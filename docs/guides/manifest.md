# Component manifest

`config/deckplate/components.yml` (shipped in the gem) is the machine-readable catalogue of every component: what it takes, what it renders, and
where its styles and behaviour live. It is meant for documentation generators and for ports (Django or Phoenix templates, plain HTML), which can
read it instead of reading the Ruby. It is generated by `bin/build-manifest` from the component classes themselves, and a spec fails when it is stale,
so it cannot drift. Do not edit it.

```yaml
format: 1
common:
  html_options: "..."          # how extra keyword arguments reach the element (shared by all components)
  colors: [primary, ..., emergency]
components:
  Data::Timeline:              # namespace and class name without "Component"
    class: Deckplate::Data::TimelineComponent
    description: "..."         # the doc comment above the class
    sheet: data                # shipped stylesheet: core, controls, forms, data or feedback (ADR 0012)
    css_block: dp-timeline     # only when the component has its own stylesheet ...
    stylesheet: app/assets/stylesheets/deckplate/components/data/timeline.css
    controllers: [dp-keypad]   # Stimulus controllers it attaches to its element
    talks_to: [dp-sound]       # controllers it calls on an ancestor (Button: the click tick, when sounds are on)
    html_options: true         # accepts extra keyword arguments (class:, data:, aria:, id: ...)
    params:                    # in constructor order
      title:  { required: true }
      color:  { required: false, default: ":primary" }          # default = the Ruby source of the default
      shape:  { required: false, variant: { values: [pill, block], default: pill } }   # closed set, from `variant`
    slots:
      events: { many: true, params: { title: { required: true }, ... } }   # a lambda slot lists its parameters
      items:  { many: true, component: MenuItem }                          # a slot that renders another component
    extends: Forms::Control    # form controls inherit the shared parameters of this abstract entry
    abstract: true             # the shared base itself: not rendered on its own
    slot_of: [Menu]            # a component that only exists as the content of a slot
    previews: [timeline/default, ...]   # Lookbook previews (this repository only)
```

Notes for a consumer:
- A component without `stylesheet` reuses the classes of another one: a form control uses the shared `dp-input` and `dp-choice` rules, the part of a
  slot (`MenuItem`, `NavItem`, `Tab`, `BarSegment`) uses the elements of its parent. `sheet` still says where its styles ship.
- `default` is source text (`":primary"`, `"false"`, `"nil"`, `'"button"'`), not a typed value.
- `variant` values are the allowed symbols; they become modifier classes (`dp-button--pill`).
- Design tokens are in `tokens.json` (see `design-tokens.md`); this file does not repeat them.

To read it from Ruby: `YAML.load_file(Deckplate::Engine.root.join("config/deckplate/components.yml"))`.
