# Changelog

All notable changes are documented here. Format: [Keep a Changelog](https://keepachangelog.com/), semantic versioning.

## [Unreleased]

### Added
- `SortableList` (`Data::SortableListComponent`, `dp-sortable`, ADR 0020): a reorderable list with move up / move down buttons for every item and a pointer drag on a grip, an announced move, a `dp-sortable:reorder` event and optional hidden form fields. JS budget raised to 40 KB raw / 12 KB gzip (ADR 0021).
- `Donut` (`Data::DonutComponent`, `dp-donut`): server-rendered SVG ring for the shares of a whole, with the total (or a `center:` text) in the middle, a legend giving each slice's value and share, and a hidden data table. Slices are told apart by colour and by text, not by colour alone; colours repeat after eight slices.
- `BarGraph` with several values per item: `keys:` names them, `grouping: :grouped` (side by side) or `:stacked` (one bar, with a total). Keys differ by colour, pattern and legend name; the hidden table gains one column per key (and a Total when stacked).
- `LineChart` (`Data::LineChartComponent`, `dp-line-chart`): server-rendered SVG line chart with round-number axes, several series (colour, dash pattern and legend name), optional `area:` fill and labelled `threshold:` line, visually hidden data table, en/fr.
- `Tooltip` extras: `placement:` (`:top`, `:bottom`, `:start`, `:end`; start/end follow the text direction; flips to the opposite side when it does not fit) and `delay:` (ms before a hover opens it; keyboard focus is never delayed).
- Hotwire Native support (ADR 0019, guide `docs/guides/hotwire-native.md`): `dp_native?`, `data-dp-native` from `dp_theme_attrs`, 48 px touch targets, no tap highlight, hover styles only under
  `(hover: hover)` everywhere, safe-area insets for toasts and the Frame drawer.

### Fixed
- `dp_select` / `Forms::SelectComponent` no longer raise on an empty list of options (a form with no choices yet is normal); only a missing (`nil`) list is rejected.
- `Panel` header bar wraps (`flex-wrap`) so a long status pill drops below the title instead of squeezing it to a column of single letters on a phone.
- A wide `Table` inside a `Section` no longer widens the page: the section grid has a `minmax(0, 1fr)` column, so the table scrolls inside its own wrapper (the `Tabs` panel gets `min-inline-size: 0` too).
- The Frame drawer (narrow screens) opened from the physical left in right-to-left text; it now opens from the start side.
- Two themes (ADR 0018): `verdant` (phosphor greens) and `high-contrast` (AAA text; the text on the pure-red emergency fill is AA), with four new palette stops (`mint`, `teal`, `lime`, `coral`),
  a stricter AAA contrast spec for `high-contrast`, an optional `--dp-track` token for meter tracks, and a single source for the theme list (`Configuration::BUILT_IN_THEMES`). Per-theme sound packs for `dp-sound` (seven packs, classic as fallback).
- Component manifest `config/deckplate/components.yml` (Phase 9): every component's parameters, defaults, variants, slots, controllers, stylesheet and previews, generated from the code
  by `bin/build-manifest` and checked by a spec; guide `docs/guides/manifest.md`. Four components gained the doc comment the manifest needs.
- `Forms::KeypadComponent` (Phase 9): a numeric code field with an on-screen pad (`dp-keypad`): real `<input>` (physical keyboard, native submit), `length:`, `masked:`, `submit:`,
  digit-count live region, RTL-aware; previews, specs and baselines.
- `Data::TimelineComponent` (Phase 9): events as an ordered list, state by icon or shape plus hidden text (never colour alone), `aria-current="step"` on the current event,
  `<time>`, per-event colours; RTL-aware; previews, specs and baselines.
- Right-to-left support (ADR 0017, guide `docs/guides/rtl.md`): logical `Elbow` corners (`top_start`, `top_end`, `bottom_start`, `bottom_end`; physical names unchanged),
  `Panel` and `Frame` mirror (Frame slots `top_start_corner` / `bottom_start_corner`, old names kept; Panel `corners: :start`), directional icons, slider fill,
  popover alignment, left-to-right data values, mirrored Frame entrance animation; RTL specs, a pixel mirror check and RTL visual baselines (`bin/visual --dir rtl`).
- Design tokens export `config/deckplate/tokens.json` (W3C format: palette, font stacks, five themes), generated by `bin/build-css`; guide `docs/guides/design-tokens.md`.

## [0.9.0] - 2026-11-17

Feature complete, private pre-release (not published; the legal checklist in `docs/PLAN.md` and the screen reader test, Q-010, are still open).

### Added
- Phase 7: `Frame animate:` entrance cascade, `Readout flicker:`, `ThemeSwitcherComponent` (`dp-theme`, cookie), opt-in sound
  (`config.sounds`, `dp-sound`, `SoundToggleComponent`, `dp_sound_attrs`; ADR 0013; guide `docs/guides/motion-sound-theme.md`).
- Metric-matched fallback fonts (ADR 0015) and a layout-shift spec; zoom/reflow (200 %, 400 %), forced-colours and touch-target specs; guides
  `accessibility.md` and `theming.md`; JS budget 30 KB / 8 KB (ADR 0014).
- Phase 8: `rails g deckplate:install` (idempotent; layout, Stimulus and Tailwind wiring), `rails g deckplate:theme`, `rails g deckplate:gallery`;
  Tailwind bridge copied by the installer (ADR 0016); `bin/integration` (plain, Tailwind 4 and built-gem host apps, nightly workflow);
  README and guides (installation, Tailwind, CSP, Turbo, upgrading); legal checklist run.

### Changed
- Sized `Bar` segments now shrink on narrow screens (reflow at 400 % zoom).
- Project skeleton (Phase 0) and ADRs 0001-0005.
- Phase 1 foundations: generated colour tokens (palette stops, roles), five themes (`classic`, `azure`, `nocturne`,
  `daylight`, `crimson`), bundled OFL fonts, `.dp-root` base styles, `Deckplate.configure`, `BaseComponent` with
  colour/size/variant concerns, view helpers (`dp_root`, `dp_theme_attrs`, `dp_color_class`, `dp_icon`, `dp_font_tags`),
  English and French locale skeletons.
- Phase 2 shapes and layout: `Spacer`, `Cap`, `Divider`, `Bar` (segments, caps, vertical), `Elbow` (four corners, transparent
  inner arc, labels), `Block`, `Bracket`, `Panel` (plain bars or elbow corners), `PageHeader`, `Section`, `Frame`
  (classic / double / minimal, container-query collapse, native-popover sidebar, `fixed` mode, skip link).
- Phase 3 controls and navigation: `Button`, `ButtonGroup`, `Toggle`, `Slider` (`dp-slider`), `Nav`/`NavItem`, `TopNav`,
  `Breadcrumb`, `Pagination`, `Disclosure`, `Tabs` (`dp-tabs`), `Menu` (`dp-menu`), `Tooltip` (`dp-tooltip`), `Modal` (`dp-modal`).
  Stateful controllers survive Turbo cache restores and morph refreshes (ADR 0007).
- Phase 4 forms: `FormField`, `TextInput`, `Textarea`, `Select`, `Checkbox`, `RadioGroup`, `Range`, `FileInput`, `DateInput`,
  `FormActions` and `Deckplate::FormBuilder` (`dp_*` methods, labels/hints/errors/required from the model, nested `fields_for`,
  first-error alert and focus). Typed values survive Turbo morph refreshes (ADR 0008). Guide: `docs/guides/forms.md`.
- Phase 5 data display: `Readout`, `DataList`, `StatusPill`, `Progress`, `Gauge`, `BarGraph`, `Sparkline`, `Table` (sortable, footer,
  empty state), `Clock` (`dp-clock`), `DataCascade`; CSP-safe mode for every component with dynamic values (`dp-values`, `dp-v-0..100`,
  ADR 0010); Turbo Stream dashboard demo. Guide: `docs/guides/data-display.md`.
- Phase 6 feedback: `Alert` (`dp-dismiss`), `ConditionBanner`, `Toast` (`dp-toast`, `dp_toast_container`, Turbo Stream usage, pause on
  hover/focus, stack limit), `Spinner`, `Skeleton`, `EmptyState`, `Callout`. Guide: `docs/guides/feedback.md`.
- Stylesheets by family (ADR 0012): `deckplate-core.css` plus `deckplate-{controls,forms,data,feedback}.css`, next to the all-in-one
  `deckplate.css`; budgets are now per sheet. Guide: `docs/guides/stylesheets.md`.
- Gzip CSS budget raised to 15 KB (ADR 0011), then replaced by per-sheet budgets (ADR 0012).
- The shipped `deckplate.css` no longer contains comments or blank lines (-23% gzip); the sources keep them.
- `bin/visual --geometry`: elbow seam, edge-straightness and transparency check in Chrome, Firefox and WebKit.

### Changed
- Geometry tokens retuned against a reference console: bar 0.9u, gap 0.35u, column 8u, outer radius 4.5u, inner radius 1.8u.
- `.dp-root` resets its margin.
